# Vinted Dyson Monitor

A Python bot that monitors newly listed Dyson vacuum cleaners on Vinted and sends Telegram notifications for matching listings.

## Features

- Monitor Vinted search results
- Sort by newest listings
- Filter Dyson V11 / V12 / V15
- Maximum price filter
- Duplicate detection
- Telegram notifications
- Random polling interval

## Requirements

- Python 3.11+
- Telegram Bot
- Vinted account (optional)
